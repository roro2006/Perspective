## Goal
The robot keeps, for each person, what that person believes about where things are: the
last position and time each object was seen, updated only from what their head camera can
actually see (segmentation pixel counts as the bench uses for the robot, projection when no
segmentation is available). The robot's own map is the truth. Objects whose believed position
is more than a threshold from the true one are flagged.

Requests that refer to the person's memory ("the red one I left on my left") are grounded on
the belief: the real grounder (Qwen3-VL-4B Q8_0 + r16 v2 LoRA, geometry condition) sees the
stored head-camera frame from when the person last saw the scene, with marks at the believed
positions; the chosen id is mapped to its current true position and the robot goes there.
Present-tense requests ("the red one on my left") are grounded on the current view as usual.
When the chosen object moved while the person couldn't see it, the robot also says so in the
person's frame ("I moved it; it's now on your right.").

## Scenarios (sim tabletop, collab.tasks.fetch_scene without the box)
1. The person sits and sees every block (each block >= MIN_VISIBLE_PX head-camera pixels).
2. They turn their head away (look behind them) or leave (head 1.5 m from the table, facing
   away); no block has any head-camera pixel.
3. The robot or a second person moves one block of the target's same-colour pair: either the
   target or its partner, to a free spot at least 0.06 m from where it was, chosen so the
   words' relation now picks the other block of the pair.
4. The person returns to the same seat (gaze jittered by up to 0.03 m) and speaks at once;
   their return frame is the "current view", observed by the tracker after the request.
True-belief controls: the same timeline with nothing moved.

## Evaluation set
Generated by `belief_bench.generate`, seeds 2101-2103 (disjoint from training: grounding
data seed 0, bench_lora_data 11-19; and from bench seed 0, bench_grounding seed 7, e2e
70000+). 120 false-belief items (target moved / partner moved half each; mover robot /
second person and away mode look-away / leave balanced by the rng), 120 controls, and 60
present-tense items after a move (reported, not gated). Memory wordings and frames
(speaker / robot, half each) as in the notes; at the time the person last saw the scene the
words must be ambiguous between viewers, as bench "marked" items are.

Systems:
- (i) current-state only: the usual pipeline on the current view and true map, words as said.
- (ii) belief-aware: memory wording -> belief grounding as above; present tense -> as (i).
- reference for controls: v2 on the same control scenes with the bench "marked" wording
  ("Hand me the {color} one on {my|your} {side}") on the current view.

## GATE (written before any evaluation; not to be changed afterwards)
A grounder error or empty answer counts as wrong. Accuracy = the resolved object id equals
the target id (the robot then goes to that id's current true position).
1. Belief-aware accuracy on the 120 false-belief items >= 0.85.
2. Current-state-only accuracy on the same items <= belief-aware accuracy - 0.30.
3. Controls: belief-aware accuracy on the 120 controls >= R - 0.03, where R is the larger
   of current-state-only accuracy on the controls and the v2 "marked"-wording reference.
4. Spoken-note flag (belief-aware system says a moved-it note) equals "the target moved
   while the person could not see it" on >= 0.95 of the 240 false-belief and control items.
Every number is reported with a 95% CI (Wilson for rates, paired bootstrap over items for
the differences); the gate is on the point estimates. Results go to out/t5_21/gate.json.
