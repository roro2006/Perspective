## Goal
Run 3 (0.45 ring-on-target on 100 scenes) learned "close, open, retry" but mostly closes in
mid-air, 4-6 cm above the block. Change the demonstrations two ways and train run 4:

- **DART-style noise throughout the descent**: the executed action is the expert's action
  plus correlated noise, the recorded label is the expert's corrective action, so the data
  covers states near the nominal path and shows how to return to it.
- **Close by state**: the expert closes only when the jaws straddle the block (jaw/block
  geometry checked every control tick); if they don't, it keeps correcting instead.

Replace the private expert helpers demos.py imports with public helpers in expert.py
(pick() and its tests unchanged). Keep demo episodes within the 60-frame (6 s) evaluation
horizon. Record about 800 episodes (varied wording, wrist camera, seeds 5000+, disjoint
from every earlier recording), train with run-3 settings (bf16, chunk 30, 10 actions per
call, about 3 h at most) into out/smolvla/run4.

## Gate (fixed before training)
On the T5-08 evaluation with n = 100 scenes (seed 50000, default run-4 settings):
- ring on target: target picks >= 0.55 (run 3: 0.45, run 2: 0.42 on the same scenes);
- ring on the partner: partner picks > target picks (the ring still steers);
- words only: target picks stay below ring-on-target picks.
End to end (setups words, lora2, oracle; out/e2e/run4, trials and choices copied from
out/e2e/run3) is reported, not gated.
