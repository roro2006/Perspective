# T5-21 notes: theory of mind (belief tracker + belief-aware grounding)

- curio_robot/belief.py: `Belief` is immutable, one per person. `observe(frame, truth, visible)`
  updates only the ids the head camera sees (`visible_ids`: >= 20 segmentation pixels in the
  sim, projection into the image otherwise) and keeps the latest frame that showed anything as
  `last_view`. `false_beliefs(truth)` flags ids more than 0.03 m from the truth. `resolve()` sends
  memory wording (`refers_to_memory`, a regex) to the belief: geometry-condition request on
  `last_view` with marks at the believed positions. Everything else goes to the current view.
  The chosen id maps to its true position. A note comes when the id is flagged ("I moved it;
  it's now on your right, nearer you.", in the person's current frame; "Someone" for a second
  person).
- Decision made before the eval: on the belief route the memory clause is removed
  (`present_reading`: "I left on my right" -> "on my right"), because the stray "left" is a
  trap. The ablation with the words as said scored the same (FB 1.000, controls 1.000).
- curio_robot/belief_bench.py: fetch_scene (no box). The person sees every block, then looks
  behind them or walks 0.8 m away (zero block pixels, checked), and one block of the target's
  pair moves >= 0.06 m so the words' relation flips. They come back (gaze jitter <= 0.03 m) and
  speak, and the tracker sees the return frame only after the request. Seeds 2101-2103.
  Counts: 120 FB, 120 control, 60 present.

- Why line 2 fails (diagnosed afterwards, nothing tuned): after the move, both blocks of the
  pair usually sit on the same side for the words' frame (84/120 FB items). The prompt then
  labels them the same, and v2 on the current view picks the OLD target in 79 of those 84, so it
  is right by accident. Present-tense items after a move show the same weakness: 0.40 for both
  systems, 28/36 wrong when the labels tie. A perfect current-view grounder would score 0 on FB
  (test_perfect_grounder_separates_the_systems). The gap is real; the baseline is inflated by
  v2's ignoring relative position when the labels tie. A follow-up card on fresh seeds could
  require the post-move labels to split, or train v2 on tied-label pairs.
- Weak: the wording is templated and the memory regex is tuned to it. An identity-omniscient
  observer is assumed (a person who sees two identical red blocks knows which is which).
  `last_view` is simply the latest frame with any object, so a partial glance replaces a full
  view. Moves are teleports between frames, with no robot arm motion. One FB miss (0103).
