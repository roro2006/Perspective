# T1-03 notes

- Implemented `flip_probability` in `curio_robot/conventions/noise.py` as a plain loop over `geometry.perturb_pose` with one `default_rng(seed)`. Signature and docstring unchanged.
- Noise-free difference is computed as `dot(p - viewer.position, viewer.right)` per point, matching `perspective.lateral`. Exact zero returns 0.5.
- Flip = `np.sign` of the noisy difference differs from the noise-free sign. Zero-noise case never flips because noisy poses equal the base pose.
- Added one import: `from curio_robot.geometry import perturb_pose`.
- Checks: `uv run pytest tests/test_t1_noise.py --strict-impl` 7 passed; `uv run pytest -q` 35 passed, 74 skipped; `uv run ruff check curio_robot tests` clean.
- Open spec point: the spec says "vectorize or keep it simple". I kept the loop. Timing test passes, but the margin under the 100 ms test bound on a slow machine is not measured.
- Open spec point: `pos_sigma` is applied to the viewer position, but position cancels in the difference, so only rotation noise can flip. This matches the card hint and is not a bug.
- Worry: the `IN_LINE` test expects p in (0.1, 0.5]. It passes, but the value depends on the seed and sample count. A change to the rng draw order would move it.
