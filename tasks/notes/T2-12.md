# T2-12 notes: curio-sim ground-eval

- New `curio_robot/sim/ground_eval.py`: `run_ground_eval(data_path, grounder, *, ids, current, max_p95_ms)` returns `(result, verdict)`. `result` is evaluate()'s dict; `verdict` is passes_gate()'s `(ok, message)`, or None without a current result. Each row is rebuilt with the image as a base64 PNG data URL and the assistant message dropped.
- `cli.py`: new `ground-eval` subcommand. Existing subcommands unchanged. Exits 1 when the gate fails.
- Decision: the correct answer is scored on the grounder's emitted `letter`, not argmax of `probs`. A None letter counts as wrong.
- Decision: `--ids` is a path to a JSON file holding a list. Unknown ids raise ValueError.
- Decision: `--out` holds only evaluate()'s dict, so it can be passed back as `--current`. The gate verdict is printed, not stored.
- Qwen's first draft called `grounder.score` twice per request and referenced a nonexistent helper. Removed. Its test draft had two bugs (image index, wrong-letter lookup) and reused a grounder past its rows. Fixed.
- Tests: `tests/test_t2_ground_eval.py` (5 tests, fake grounder, no network). Accept, full suite (176 passed) and ruff pass.
