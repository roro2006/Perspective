# T1-07 notes: decision recorder

- Implemented `DecisionRecorder` (append mode, parent dir created, flush per line) and
  `load_records` in `curio_robot/recorder.py`. VERSIONS, DecisionRecord and line format unchanged.
- Added a module-level `_plain` that recurses through slotted dataclasses (`fields` + `getattr`),
  dicts, lists/tuples and sets; numpy arrays become lists rounded to 4, numpy scalars become
  Python scalars. Kept local rather than importing `episode_log._plain`, which is not recursive.
- Open choices: only arrays are rounded; plain floats (posterior, confidence, t) are written as-is.
  Dict keys are coerced to str so JSON round-trips predictably.
- `load_records` skips blank lines and ignores lines whose kind is neither decision nor outcome.
  Outcome lines are not returned themselves; an outcome before its decision still joins.
- Worry: a crash mid-write could leave a truncated last line, which makes `load_records` raise
  on `json.loads`. Not handled since the spec says nothing; easy to tolerate later if wanted.
