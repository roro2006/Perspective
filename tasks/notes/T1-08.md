# T1-08 notes
- Orchestrator now decides partials and finals via readings -> belief.posterior -> decide. New optional kwargs: person, profiles (ProfileStore), recorder (DecisionRecorder), belief (injected, wins over profiles). RuntimeConfig gains person/profiles_dir/decisions_path; Runtime builds the store/recorder only when the paths are set and closes the recorder. run_live passes the three through (CLI flags not added: the CLI module isn't owned).
- Partials still need a colour before anything moves ("hand me the" would otherwise hedge toward every object). Hedge drifts once ("approach"), act goes "speculative"; a partial record is written only when (kind, object_id) changes.
- Final hedge/ask: stop, ask decision.question or "Your left or mine?". The next final is an answer if it says mine/my/yours/your (last wins) and names no other colour; it records stage "final", learns "answered", goes with tag "answered".
- Accept window: arrival arms it for 2 s. The next utterance's start does not learn immediately: its first partial/final does, unless that is a stop word ("no ...") which cancels it, so "no, the other one" after arrival is a correction, not accept+correct. Any interrupt cancels it. Orchestrator.close() counts a still-open window as accepted (the session ended without a complaint).
- Each pending decision is learned from once: after accept, correction or answer it's cleared, so a later outcome can't double-count.
- Corrections record a "correction" stage and learn with p_flip from noise.flip_probability(speaker obj, robot obj, human_pose); outcomes are written against the original decision's utterance. VLM replies are recorded as "vlm"; a redirect makes the VLM's pick the one later outcomes judge.
- Confirmations of non-explicit left/right now name the frame actually chosen (via confirmation() on a rewritten phrase); confirmation() itself is unchanged.
- Worry: a "no" arriving after the 2 s window learns "corrected" on a fresh decision only if it hasn't been accepted; since accepted clears it, a late correction teaches nothing. Also tests/test_t1_runtime.py imports helpers from tests.test_runtime (works via rootdir, as conftest does).
