# T3-06 notes

- collab/run.py: one Runtime per task so the belief carries across goals; the person is
  a ReactiveVoice whose react() returns answers, corrections or the next goal.
- Live ids are matched to true ids by nearest position and the match is remembered:
  with view-off the arm hides the block from the robot camera as it reaches, and the
  object drops out of the live map (found in a sample run; fixed).
- Corrections: 'no, the other one' within a same-colour pair, else 'no, the <colour> one'.
  At most 2 per goal, then the person gives up on it (goal not done).
- 'Which one?' gets the goal said again without 'that one'; 'I don't see' gives up the goal.
- Deictic goals: the person's head turns to the goal, applied on the world's thread.
- Sample (seed 3, 4 goals): own-frame user 1 correction view-off vs 0 view-on;
  robot-frame user 0 view-off vs 1 view-on (the belief has to learn their habit).
