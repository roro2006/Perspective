# T1-05 notes: per-person profile store

- Implemented ProfileStore in curio_robot/conventions/profiles.py; signatures and docstrings unchanged.
- Names are checked with re.fullmatch(r"[A-Za-z0-9_-]{1,64}") in load, save and reset before any filesystem access (ValueError).
- save() creates root with parents, writes via tempfile.mkstemp(dir=root, suffix=".tmp") then os.replace; the temp file is unlinked if the write fails.
- load() returns ConventionBelief() for a missing file, and for unreadable or malformed JSON (logs a warning, never raises).
- reset() uses Path.unlink(missing_ok=True).
- Open question: load() on a file missing the "belief" key is treated as corrupt (warning, prior). The spec does not say otherwise.
